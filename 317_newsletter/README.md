# 317 Squadron newsletter (retired)

The newsletter now lives on the squadron website,
<https://www.317atc.co.uk/newsletter>, with every back issue at
`/newsletter/issue-N`. Staff upload and edit issues in the SMS (Tools →
Newsletter Management), which commits them to the `cadet-website` repo.

This app only redirects now (`next.config.ts`), so links already shared to
`newsletter.317atc.co.uk` and its PDFs keep working. Once those have had time
to age out, the Vercel project and this repository can be archived.
